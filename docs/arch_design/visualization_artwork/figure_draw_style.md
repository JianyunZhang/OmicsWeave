# OmicsWeave 海报衍生绘图标准

2026-11-21 · 参考用户提供的 `figure_draw` 图件

此标准适用于后续研究流程图、器官小多图、低密度通路示意及论文图版的视觉组织。原图中的剂量、比较组、效应方向、样本量、显著性与机制陈述属于各自实验。新图从本次分析结果及图注读取这些字段。

## 风格与版式

| 元素 | 从原图提取的规则 | 后续绘制 |
| --- | --- | --- |
| 主标题 | 白底、深色粗体无衬线。分段标题与子图标注形成明确层级。 | 白底 `#FFFFFF`、文字 `#232323`。标题左对齐，图版面板字母保持同一位置。图表正文用常规字重，实际字号按输出尺寸验收。 |
| 研究流程 | 写实小鼠、器官和设备组成各阶段，阶段间留出贯通空白。 | 线性流程用单一中性色箭头，横向、小多图或纵向均可。图标与底部标签对齐，样本来源、器官与仪器型号由实际项目确定。 |
| 代谢通路 | 节点使用有深色描边的圆角胶囊。酶名置于连接线附近，相邻通路以色族和文字区分。 | 实线箭头表示明确的方向关系。需要压缩多步时用虚线及“多步”标签。通路类别和证据强度分别编码，避免通过重复罗马数字建立类别。 |
| 多组织结果 | 按组织排成行，同类指标并排，小图的坐标位置和图例较一致。 | 组织缩略图放在面板边缘，保留统一单位、对比顺序、正常范围与缺失语义。重复图例可集中一次展示。 |
| 定量图 | 清楚显示分组、个体或误差条，颜色和标记可帮助对照。 | 使用 `poster_editorial`。图注声明样本量、误差含义和检验，多组对比配合点形或线型。继续使用项目已有的方向色与证据样式。 |

## 复用验收

1. 利用资产清单追溯到源文件、裁切框和 SHA-256。海报裁出的器官与设备在新图中仍为嵌入的位图，标题、框线和箭头可在 SVG 编辑器中修改。
2. 选图时复核物种、解剖结构和项目语义。旧海报的结果子图作为版式参考。新的数据图用本次结果包重绘。
3. 对发表或公开分发的图版核实所用图标的原始来源及许可，保持必要署名。示意子图与独立原件的来源记录留在本地筛选清单。
