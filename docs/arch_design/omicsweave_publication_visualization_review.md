# OmicsWeave 出版图件与文稿规划评估

2026-11-20 · 对 [统一绘图与图文摘要方案](omicsweave_visualization_and_graphical_abstract.md) v1.0 的评估

## 总体判断

统一主题、统计图复用、图 E 的正文与全量审计视图，以及独立的小规模图文摘要，适合作为出版工作流的绘图底座。将目标扩展到可投稿的论文图像与文稿，需要增加主张与证据追踪、按目标期刊验收实际输出、以及从同一结果来源生成图注和结果段的工作流。

## 按优先级处理

| 优先级 | 当前观察 | 实施与验收 |
| --- | --- | --- |
| P0 图文摘要的证据归属 | 自动生成器按枢纽最高等级和重复反应行汇总，随后把较强端点的等级、方向和强度交给连线。任何符合条件的 TCA 耦合组也会触发所有入 TCA 边的耦合标记。 | 将生化拓扑、净流方向、条件间效应和证据等级分别存储。实测边由明确的反应或对比行支持，记录来源、区室、单位、区间、判定规则与耦合组。先让自动生成的拓扑边保持中性，再为存在直接证据的边设置样式。 |
| P0 丰度、通量、覆盖与未知状态 | “Pool stable” 来自池丰度中位数阈值。多数票可能弱化相反方向，重复的耦合反应可能放大同一个检验，`region_summary` 参数目前未被摘要聚合器消费。 | 在摘要中保留冲突、未检出、未测、不可辨识和样本不足。只有在分析规则支持时使用稳定性陈述。分别列出反应展示数和独立检验数，明示筛选、缺失和背景知识来源。 |
| P0 物理版式与导出 | `nature_editorial` 是视觉预设。`publication` 输出的实际版心、最小字号、标签碰撞和 PDF 字体回退尚未作为验收条件。 | 建立按期刊及稿件部件区分的版式配置，检查 PDF 页面框、最终字号、线宽、字体嵌入和特殊字符。正文按科学问题重排图 E，保留完整图谱作为补充或审计交付。记录样本量、色标单位、CI/FDR 图例并在灰度和色觉模拟下复核。 |
| P1 主文稿、图注和源数据 | 当前有结果包查询、统计表和整合报告，可作为输入。现方案重心在渲染，尚缺图版、图注、源数据与结果段共同使用的证据清单。 | 固定显式运行 ID 与结果契约。给每个 `claim_id` 关联面板、表与行键、组织、比较方向、单位、效应量、区间、检验、校正、样本量、缺失/筛选及文件哈希。生成图注草稿、Source Data 和可审阅的结果段，再由作者确认措辞和机制推断。 |
| P2 图文摘要与对外传播 | 三套风格用于不同阅读场景，风格、期刊部件和证据级别需要各自配置。 | 正文统计图和机制图优先纯白极简。低密度摘要根据目标期刊约束选择极简或手绘。像素风优先汇报、项目文档和科普。摘要先确定一个主结论，再选择枢纽、连线和必要的可视图例。 |

Nature 研究图指南给出的单栏、双栏及最大图高分别为 89、183、170 mm，并规定普通图中文字的大小范围和可编辑字体。正文图、Extended Data 和图文摘要各有尺寸及交付规范。锁定目标刊及文章类型后，应按当时的作者指南设置参数。颜色用于效应方向时，还应排查同一图中的分类色是否复用了方向色。[Nature 图版规范](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/) · [Nature Extended Data](https://research-figure-guide.nature.com/figures/extended-data-formatting-guidelines/) · [Cell Press 图文摘要](https://crosstalk.cell.com/blog/attract-readers-at-a-glance-with-your-graphical-abstract)

### 真实结果包抽查

固定 DIO 结果包 `run_20261118_195428_674e`，样例为肝脏 `HFD_vs_LFD`。使用现有 CLI 重绘图 E（`publication`）和 3 套摘要，并使用 `pdftoppm` 渲染 4 个 PDF 页面、检查成品页面尺寸与 PDF 文本。

- 图 E 的 PDF 成品为 **363.3 × 311.8 mm**，最小提取文字 **3.07 pt**。缩至 183 mm 宽时，这部分文字约为 1.55 pt。目视可见部分徽章与邻近标注过密。
- 三套摘要的 PDF 成品均为 **221.0 × 182.5 mm**。个别边标签被卡片覆盖，极简和手绘导出时报告 `FADH₂` 的下标字形缺失。三套摘要 SVG 均保留矢量元素，无嵌入位图。
- 摘要生成 10 个枢纽和 10 条连线，其中 5 条连线获得 L2。图 E 视图中只有 `CS_m`、`ACONT_m` 和 `ICDH_m` 三条反应达到 L2，其中后两条共享 `ACONT_m` 耦合组。摘要给“脂肪酸 → TCA”等拓扑边继承了 L2 和耦合轨道，展示了当前算法为何需要边级追踪。
- 该次工作限于一个实际组织和对比的技术与呈现抽查。优先级 P0–P2 为后续拟实施项，当前数据驱动摘要以内部草稿使用，投稿前须核对机制边、图注和具体期刊要求。

## 可先制作的矢量资产

首批资产提供 24 个语义 ID，每个 ID 均有 `nature_editorial`、`editorial_ink` 和 `pixel_abstract` 版本。文件使用统一的 `0 0 32 32` 透明画布，像素版由 16×16 逻辑网格上的矢量路径构成。清单记录 ID、类别、中文释义与对应资源路径。[SVG 资产清单](../../src/omicsweave/visualization/assets/glyphs/manifest.json)

| 类别 | 数量／风格 | 调用约定 |
| --- | ---: | --- |
| 代谢物与通路概念 | 13 | 包括葡萄糖、丙酮酸、核苷酸、TCA、酮体、脂类、氨基酸、ATP 等。概念符号用于辅助读图，具体化学结构应使用可核验的结构标识与独立制图流程。 |
| 布局网格 | 2 | 方格与点阵按方形画布平铺。统计图默认沿用正文主题的网格设置。 |
| 节点标记 | 3 | 通用代谢物池、通过图例定义统计阈值的双环节点、缺测节点。图例需要提供具体缺测含义。 |
| 反应尺度 | 3 | 单步反应、跨区室运输、聚合模块。真实箭头方向和是否可逆由当前反应及其区室配置说明。 |
| 证据等级 | 3 | L1、L2、L3 由 1、2、3 个实心点或像素格编码。展示文字由绘图模块添加，等级采用项目定义。 |
